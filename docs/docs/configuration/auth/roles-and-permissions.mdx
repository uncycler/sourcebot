Sourcebot provides different role types to help you control access and permissions across your organization.

| Role | Permission |
| :--- | :--------- |
| `Owner` | Owners have full administrative control over all organization-level settings, including user management and access control. |
| `Guest` | Guests are users that access Sourcebot without an account when [anonymous access](/docs/configuration/auth/access-settings#anonymous-access) is enabled. Guests can use some features, such as code search and browsing files. Guests **cannot access** organization-level administration pages. |

## Default role assignment

Every user who joins your organization is assigned the `Owner` role. Roles cannot be changed from the UI.

## Leaving an organization

You can leave the organization from **Settings → Members** as long as at least one other owner exists.
